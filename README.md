# brokerandreahriosa — sitio listo para publicar

Esta carpeta es el sitio completo, ya compilado. No necesita instalar nada.

| Archivo / carpeta | Contenido |
|---|---|
| `index.html` | La página. Ábrela con doble clic para ver el sitio. |
| `support.js` | El código del sitio (animación, menú, formulario, etc.). |
| `assets/` | Estilos (`style.css`), favicon, fotos (`assets/images`) y fotogramas de la animación de entrada (`assets/intro`). |
| `vendor/` | Tipografías de terceros (Cormorant Garamond y Manrope). |
| `README.md` | Este archivo. |

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube TODO el contenido de esta carpeta
   (Add file → Upload files → arrastra los archivos y carpetas → Commit changes).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. En 1–2 minutos el sitio estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

Comprueba que la carpeta `assets/intro` se subió completa (240 imágenes).
